AI랑 같이 만드는
나만의 English 단어 학습장

오늘 배울 기술은 딱 두 개입니다. 저장(Ctrl+S), 새로고침(F5). 나머지는 AI에게 부탁하면 됩니다. 아래 미션을 위에서부터 하나씩 해치우세요. 적은 내용은 이 브라우저에 저장되니 창을 닫았다 열어도 그대로 있습니다.

준비 5분

코드를 담을 빈 그릇부터 만듭니다. 여기서 막히면 손을 드세요.

  1. 바탕화면에 내단어장 폴더를 만듭니다.
  2. 메모장(또는 VS Code)을 열고 아무것도 쓰지 않은 채 저장합니다.
  3. 파일 이름은 index.html, 파일 형식은 모든 파일, 인코딩은 UTF-8로 저장합니다.
  4. 저장된 파일을 더블클릭해 브라우저에 하얀 화면이 뜨면 성공입니다.
제일 많이 걸려 넘어지는 곳파일 형식을 "텍스트 문서"로 두면 index.html.txt가 되어 열리지 않습니다. 인코딩을 UTF-8로 안 하면 한글 뜻이 네모로 깨집니다.

미션 1 · 단어 카드 뼈대 받기 15분

AI에게 "단어장 만들어줘"라고만 하면 매번 다른 게 옵니다. 조건을 붙이면 내가 고칠 수 있는 코드가 옵니다.

  1. 아래 프롬프트를 복사해 AI 채팅창에 붙여넣습니다.
  2. 받은 코드를 전부 복사해 index.html에 붙여넣고 저장합니다.
  3. 브라우저에서 새로고침. 카드가 보이면 한 번 눌러보세요. 뒤집히면 성공입니다.
HTML, CSS, JavaScript를 index.html 한 파일에 담아줘.
1) 영어 단어 카드: 앞면에 영어 단어, 누르면 뒤집혀서 뜻과 예문이 보이게
2) 이전 / 다음 버튼과 "3 / 20" 같은 진도 표시
3) 단어 목록은 JS 맨 위에 배열로 모으고 "여기만 고치세요" 주석 달기
   형식은 { en:'apple', ko:'사과', ex:'I eat an apple.' }
4) 초등학생도 읽을 수 있게 모든 줄에 한국어 주석
5) 외부 라이브러리 없이, 설명은 코드 아래 5줄 이내로

미션 2 · 내 단어 채우기 25분

오늘 외우고 싶은 단어를 적으세요. 시험 범위 단어면 가장 좋습니다. 다 적고 버튼을 누르면 코드에 붙여넣을 문장이 자동으로 만들어집니다.

English뜻예문 (비워도 됩니다)듣기 
위 표를 채우고 "내 코드 만들기"를 누르면 여기에 나옵니다.
어디에 붙여넣나요AI가 준 코드에서 여기만 고치세요 주석이 붙은 const WORDS = [ ... ]; 부분을 통째로 바꿔치기하면 됩니다. 모르겠으면 AI에게 "이 코드를 어디에 넣어야 해?"라고 물어보세요.
한 개 먼저, 그다음 전부스무 개를 한꺼번에 넣고 틀리면 어디가 문제인지 못 찾습니다. 한 줄만 바꿔 저장해보고, 잘 되면 나머지를 채우세요.

미션 3 · 발음 읽어주기 넣기 15분

오늘의 하이라이트입니다. 녹음도, 설치도 필요 없어요. 브라우저 안에 이미 목소리가 들어 있습니다. 위 표의 🔊 버튼으로 미리 들어볼 수 있어요.

기존 코드에 기능 하나만 추가해줘. 나머지는 건드리지 마.
- 카드에 스피커 버튼을 넣고, 누르면 그 영어 단어를 소리로 읽어주게
- 브라우저에 내장된 음성 기능(speechSynthesis)을 쓰고, 말하는 속도는 조금 느리게
- 소리를 지원하지 않는 브라우저면 "이 브라우저는 소리를 지원하지 않아요"라고 안내
추가되거나 수정된 줄만 알려주고, 어디에 붙여넣는지 위치도 알려줘.

숫자 하나만 바꿔보기

  1. voice.rate = 0.85 에서 숫자를 0.6으로 바꾸면 어떻게 될까요? 바꿔 보고 들어보세요.
  2. voice.lang = 'en-US' 를 'en-GB'로 바꾸면 영국식 발음이 됩니다. 차이가 들리나요?
소리가 안 나면기기 음량과 무음 스위치를 먼저 확인하세요. 그리고 소리는 반드시 버튼을 눌렀을 때만 납니다. 저절로 나게 하는 건 브라우저가 막아둡니다.

미션 4 · 퀴즈 붙이기 15분

나를 시험해 주는 기능을 넣습니다. 기능은 반드시 하나씩. 발음과 퀴즈를 한꺼번에 시키면 멀쩡하던 카드가 깨져서 돌아옵니다.

기존 코드에 기능 하나만 더 추가해줘. 나머지는 건드리지 마.
- 카드 아래에 "이 단어의 뜻은?" 퀴즈를 만들고 보기 4개를 버튼으로 보여줘
- 정답 하나와, 다른 단어들의 뜻에서 가져온 오답 3개를 섞어서 보여줘
- 누르면 정답은 초록, 오답은 흐리게 표시하고 맞은 개수와 틀린 개수를 세어줘
추가되거나 수정된 줄만 알려주고 붙여넣을 위치도 알려줘.

미션 5 · 무드 고르기 20분

여기가 진짜 재미있는 부분입니다. 색 네 개와 폰트를 고르면 아래 미리보기가 바뀌고, AI에게 보낼 프롬프트 문장이 자동으로 완성됩니다.

이 무드를 AI에게 설명하는 문장


  

    
    
  

  
"예쁘게 해줘"는 금지어예쁘다는 기준은 사람마다 다릅니다. 대신 장면을 말하세요. "수업 끝난 교실의 초록 칠판", "문구점 젤리 스티커", "새벽 게임방 네온"처럼요.






  
막혔을 때 에러 구조대

  
화면이 하얗게 비어요
단어 목록에서 작은따옴표나 쉼표가 빠진 경우가 대부분입니다. F12 → Console의 빨간 글씨와 줄 번호를 AI에게 그대로 보내고 "이 줄만 고쳐줘"라고 하세요.

  
발음이 안 들려요
음량과 무음 스위치를 먼저 확인하세요. 그래도 안 되면 버튼을 눌러서 소리를 내는 게 맞는지 확인합니다. 저절로 나는 소리는 브라우저가 막습니다.

  
발음이 한국어처럼 들려요
voice.lang 설정이 빠졌거나 'ko-KR'로 되어 있습니다. voice.lang = 'en-US' 로 바꾸세요.

  
카드가 안 뒤집혀요
뒷면에 rotateY(180deg)가 빠진 경우입니다. "카드 뒷면이 안 보여. 뒤집기 부분만 고쳐줘"라고 요청하세요.

  
뒷면 글자가 거울처럼 뒤집혀 보여요
backface-visibility 설정이 빠졌습니다. 같은 방식으로 그 부분만 고쳐달라고 하세요.

  
단어가 하나만 나와요
목록 중간에 쉼표가 빠져 배열이 끊긴 겁니다. 줄 끝마다 쉼표가 있는지 한 줄씩 확인하세요.

  
한글 뜻이 네모로 깨져요
저장할 때 인코딩이 UTF-8이 아니었습니다. 다른 이름으로 저장에서 인코딩을 UTF-8로 바꿔 다시 저장하세요.

  
AI가 코드를 통째로 새로 만들어요
"다시 만들어줘"라고 하면 그렇게 됩니다. 기존 코드는 그대로 두고 이 부분만 고쳐줘라고 말하세요.
