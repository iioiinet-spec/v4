강의 개요

왜 하필 영어 단어장인가

수업이 끝나면 학생은

  • 내가 고른 단어 20개가 담긴 학습장을 브라우저에 띄운다
  • 버튼을 누르면 컴퓨터가 영어 발음을 읽어주는 기능을 직접 넣어본다
  • 데이터(단어 목록)와 화면이 연결되어 있다는 것을 몸으로 안다
  • AI에게 3단계로 요청하는 습관을 가진다
핵심 : 외우는 수업이 아니라 만드는 수업

이 소재가 좋은 이유

  • 학생마다 단어가 달라서 결과물이 절대 똑같이 나오지 않는다
  • 발음 읽어주기가 설치 없이 브라우저 기능만으로 된다 — 가장 큰 환호 포인트
  • 집에 가져가면 실제로 쓰게 된다. 시험 전날 열어보는 학생이 생긴다
  • 영어 선생님, 학부모에게 보여주기 좋은 결과물이다
강사 한마디 : 오늘 만든 건 과제가 아니라 내 물건입니다

  • AI = 손이 빠른 조수, 나 = 무엇을 만들지 정하는 사람이라는 역할 분담 설명
  • index.html 만들어 브라우저로 여는 것까지 전원 확인
  • 오늘 외우고 싶은 단어 20개를 종이에 먼저 적게 한다 (코딩보다 이게 먼저)

단어 카드 만들기

  • 따옴표와 쉼표가 빠지면 어떻게 되는지 일부러 한 번 보여주기

40분전개 2

소리 넣고 퀴즈 붙이기

  • 속도를 느리게(rate 0.85) 바꿔보며 숫자 하나로 결과가 달라지는 경험
  • 네 개 중 뜻 고르기 퀴즈와 점수 표시 추가
  • 기능은 한 번에 하나씩. 두 개를 한꺼번에 시키면 멀쩡하던 것도 흔들린다

AI 프롬프트 치트키

순서대로 쓰면 실패 확률이 확 줄어듭니다

1

뼈대 요청

기능과 파일 형태를 못 박습니다. 여기서 욕심내면 코드가 길어져 손을 못 댑니다.

HTML, CSS, JavaScript를 index.html 한 파일에 담아줘.
1) 영어 단어 카드: 앞면에 영어 단어, 누르면 뒤집혀서 뜻과 예문이 보이게
2) 이전 / 다음 버튼과 "3 / 20" 같은 진도 표시
3) 단어 목록은 JS 맨 위에 배열로 모으고 "여기만 고치세요" 주석 달기
   형식은 { en:'apple', ko:'사과', ex:'I eat an apple.' }
4) 초등학생도 읽을 수 있게 모든 줄에 한국어 주석
5) 외부 라이브러리 없이, 설명은 코드 아래 5줄 이내로
2

무드 수정

형용사 대신 장면을 주고, 색은 코드값으로 지정합니다.

방금 만든 코드의 디자인만 바꿔줘. 기능과 구조는 그대로.
무드: 창가에 앉아 공부하는 늦은 오후
- 배경 #fff8ee, 카드 #ffffff, 글자 #3d3228, 포인트 #e08a4b
- 영어 단어는 구글 폰트 'Fredoka', 한글은 'Jua' 적용 (link 태그 포함)
- 카드 모서리는 24px로 둥글게, 그림자는 아주 옅게
- 색은 전부 :root의 CSS 변수로 빼고 변수마다 한국어 주석
바뀐 CSS 부분만 보여줘.
3

기능 추가

한 번에 하나씩. 오늘의 하이라이트인 발음부터 넣습니다.

기존 코드에 기능 하나만 추가해줘. 나머지는 건드리지 마.
- 카드에 스피커 버튼을 넣고, 누르면 그 영어 단어를 소리로 읽어주게
- 브라우저에 내장된 음성 기능(speechSynthesis)을 쓰고, 말하는 속도는 조금 느리게
- 소리를 지원하지 않는 브라우저면 "이 브라우저는 소리를 지원하지 않아요"라고 안내
추가되거나 수정된 줄만 알려주고, 어디에 붙여넣는지 위치도 알려줘.

말투보다 조건

"예쁘게"는 매번 다른 결과가 옵니다. 색상값, 폰트 이름, 카드 개수처럼 확인할 수 있는 조건을 주세요.

되돌릴 지점 남기기

마음에 드는 버전이 나오면 index_v1.html로 복사해 둡니다. 실험이 과감해집니다.

모르면 되묻기

"이 줄이 하는 일을 초등학생도 알게 한 줄로" 라고 물으면 AI가 좋은 해설자가 됩니다.

  --ink:   #16243d;   /* 기본 글자색 */
  --sub:   #8794ae;   /* 흐린 글자색 */

<script>
/* ③  내 단어 넣는 곳 ─ 여기만 내 단어로 바꾸면 '내 단어장'이 됩니다.
      한 줄이 단어 하나입니다. 작은따옴표와 쉼표를 빠뜨리지 않도록 조심하세요. */
const WORDS = [
  { en:'apple',   ko:'사과',     ex:'I eat an apple every morning.' },
  { en:'school',  ko:'학교',     ex:'My school is near the park.' },
  { en:'friend',  ko:'친구',     ex:'She is my best friend.' },
  { en:'weather', ko:'날씨',     ex:'The weather is nice today.' },
  { en:'practice',ko:'연습하다', ex:'I practice English every day.' },
];

/* ─── 여기부터는 AI가 만들어 준 부분입니다. 그대로 두어도 됩니다. ─── */

let idx = 0;  // 지금 보고 있는 단어 번호 (0부터 시작)

// 화면에 현재 단어를 그려 넣는 함수
function show(){
  const w = WORDS[idx];
  document.getElementById('en').textContent = w.en;
  document.getElementById('ko').textContent = w.ko;
  document.getElementById('ex').textContent = w.ex;
  document.getElementById('count').textContent = (idx + 1) + ' / ' + WORDS.length;
  document.getElementById('barFill').style.width =
    Math.round((idx + 1) / WORDS.length * 100) + '%';
  document.getElementById('flip').classList.remove('on');  // 카드 앞면으로 되돌리기
}

// 카드 뒤집기
document.getElementById('flip').onclick = function(){
  this.classList.toggle('on');
};

// 다음 단어 / 이전 단어
document.getElementById('next').onclick = function(){
  idx = (idx + 1) % WORDS.length;     // 마지막 다음은 다시 처음으로
  show();
};
document.getElementById('prev').onclick = function(){
  idx = (idx - 1 + WORDS.length) % WORDS.length;
  show();
};

// 발음 읽어주기 ─ 브라우저에 들어 있는 음성 기능을 사용합니다
document.getElementById('say').onclick = function(){
  if (!('speechSynthesis' in window)){
    alert('이 브라우저는 소리를 지원하지 않아요.');
    return;
  }
  const voice = new SpeechSynthesisUtterance(WORDS[idx].en);
  voice.lang = 'en-US';   // 영어 발음으로 읽기
  voice.rate = 0.85;      // 말하는 속도 (1이 보통, 작을수록 느림)
  speechSynthesis.cancel();   // 읽던 것이 있으면 멈추고
  speechSynthesis.speak(voice);
};

show();   // 첫 단어 보여주기
</script>
</body>

증상원인현장 대처
화면이 하얗게 비어요단어 목록에서 따옴표나 쉼표가 빠짐F12 → Console의 빨간 줄 번호를 AI에게 그대로 붙여넣고 "이 줄만 고쳐줘". 가장 흔한 상황이라 미리 시연해 두면 좋습니다
발음이 안 들려요기기 음량, 무음 모드, 또는 첫 클릭 전 자동 재생 차단반드시 버튼을 눌러 소리를 내게 하고(자동 재생은 막힙니다), 음량과 무음 스위치를 먼저 확인시킵니다
발음이 한국어처럼 들려요lang 설정이 빠졌거나 ko-KR로 되어 있음voice.lang = 'en-US' 한 줄을 같이 찾아봅니다. 영국식은 'en-GB'
카드가 안 뒤집혀요back 면에 rotateY(180deg)가 빠짐"카드 뒷면이 안 보여. 뒤집기 부분만 고쳐줘"라고 요청
뒷면 글자가 거울처럼 보여요backface-visibility 설정 누락같은 방식으로 그 부분만 요청. 원리를 거울에 비유해 설명하면 이해가 빠릅니다
단어가 하나만 나와요목록 사이 쉼표 누락으로 배열이 끊김줄 끝마다 쉼표가 있는지 한 줄씩 짚어봅니다
AI가 코드를 통째로 새로 만듦"다시 만들어줘"라고 요청"기존 코드는 그대로 두고 이 부분만"을 구호처럼 반복시킵니다
한글 뜻이 네모로 깨져요meta charset 누락문서 맨 위 charset 줄을 확인. 저장할 때 인코딩도 UTF-8로
