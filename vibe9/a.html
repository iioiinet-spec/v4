강의 개요

왜 이 수업을 하는가

이 수업이 끝나면 학생은

  • 내 손으로 고른 무드의 웹 페이지를 브라우저에 띄운다
  • AI에게 원하는 결과를 얻어내는 3단계 프롬프트 습관을 갖는다
  • CSS 변수 6줄, 데이터 배열 한 곳만 고치면 전부 달라진다는 걸 체감한다
  • AI가 준 코드에서 "내가 바꿀 곳"을 스스로 찾아낸다
핵심: 문법 암기 0, 결과물 1개

바이브 코딩이라 부르는 이유

  • 어려운 계산(날짜 차이, 요일, 레이아웃)은 AI 담당
  • 취향 결정(색, 폰트, 배치, 문구)은 사람 담당
  • 코드를 외우는 게 아니라 고쳐 쓰는 감각을 기른다
  • 완성 기준은 "작동"이 아니라 "내 마음에 드는가"
강사 한마디: 오늘은 타자보다 취향이 실력입니다

1

뼈대 요청

기능과 파일 형태를 못 박아 둡니다. 여기서 욕심내면 코드가 길어져서 손을 못 댑니다.

HTML, CSS, JavaScript를 index.html 한 파일에 담아줘.
1) 화면 위쪽에 D-Day 카운터: 목표 이름과 남은 날짜를 크게 표시
2) 아래쪽에 월~금 5교시 시간표 표
3) 시간표 내용과 목표 날짜는 JS 맨 위 상수에 모아두고, 주석으로 "여기만 고치세요"라고 표시해줘
4) 초보자가 읽을 수 있게 모든 줄에 한국어 주석
5) 외부 라이브러리 없이, 설명은 코드 아래에 5줄 이내로
2

무드 수정

형용사 대신 구체적인 장면을 주면 결과가 확 좋아집니다. 색은 코드값으로.

방금 만든 코드의 디자인만 바꿔줘. 기능과 구조는 그대로.
무드: 늦은 밤 스터디 카페, 차분하고 눈이 편안한 느낌
- 배경 #12161f, 카드 #1b2130, 글자 #e8ecf7, 포인트 #7be0c8
- 구글 폰트 'Gowun Dodum' 적용 (link 태그 포함)
- 색은 전부 :root의 CSS 변수로 빼고, 변수 이름 옆에 한국어 주석
- 모서리는 살짝 둥글게, 그림자는 아주 옅게
바뀐 CSS 부분만 보여줘.
3

기능 추가

한 번에 하나씩. 두 개 이상 요청하면 멀쩡하던 코드가 같이 흔들립니다.

기존 코드에 기능 하나만 추가해줘. 나머지는 절대 건드리지 마.
- 지금 시각 기준으로 오늘 요일의 현재 교시 칸에 테두리를 둘러 강조
- 주말이면 "오늘은 쉬는 날" 문구 표시
- 1분마다 자동으로 갱신
추가되거나 수정된 줄만 알려주고, 어디에 붙여넣으면 되는지 위치도 알려줘.

말투보다 조건

"예쁘게"는 결과가 매번 달라집니다. 색상값, 폰트 이름, 칸 개수처럼 확인 가능한 조건을 주세요.

<script>
/* ③  내 데이터 넣는 곳 ─ 아래 세 덩어리만 내 것으로 바꾸면 '내 시간표'가 됩니다. */
const TITLE  = '세영 2학기 시간표';
const TARGET = { label:'기말고사', date:'2026-12-10' };  // 날짜는 반드시 YYYY-MM-DD
const DAYS   = ['월','화','수','목','금'];
const PERIODS = [
  //  시작시간,  월      화      수      목      금   (빈 교시는 '' 로 두세요)
  { time:'09:00', subjects:['국어','수학','영어','과학','코딩'] },
  { time:'10:00', subjects:['수학','영어','국어','코딩','체육'] },
  { time:'11:00', subjects:['영어','코딩','수학','국어','미술'] },
  { time:'13:00', subjects:['과학','국어','체육','수학','영어'] },
  { time:'14:00', subjects:['코딩','미술','과학','영어','동아리'] },
];

/* ─── 여기서부터는 AI가 만들어 준 부분입니다. 그대로 두어도 됩니다. ─── */

// 남은 날짜 계산 : 오늘 자정과 목표 자정을 빼서 하루 단위로 환산
function updateDday(){
  const target = new Date(TARGET.date + 'T00:00:00');
  const n = new Date();
  const today = new Date(n.getFullYear(), n.getMonth(), n.getDate());
  const diff = Math.round((target - today) / 86400000);
  document.getElementById('ddayLabel').textContent = TARGET.label;
  document.getElementById('ddayNum').textContent =
    diff > 0 ? 'D-' + diff : (diff === 0 ? 'D-DAY' : 'D+' + Math.abs(diff));
  document.getElementById('ddayDate').textContent = TARGET.date + ' 까지';
}

// 지금 몇 교시인지 찾기 : 현재 시각이 어느 교시 구간에 있는지 확인
function currentPeriod(){
  const n = new Date();
  const mins = n.getHours() * 60 + n.getMinutes();
  for (let i = PERIODS.length - 1; i >= 0; i--){
    const [h, m] = PERIODS[i].time.split(':').map(Number);
    const start = h * 60 + m;
    if (mins >= start && mins < start + 50) return i;   // 한 교시 50분 기준
  }
  return -1;
}

// 시간표 그리기 : 칸을 하나씩 만들어 화면에 붙입니다
function drawTable(){
  const table = document.getElementById('table');
  table.textContent = '';                       // 기존 내용 비우기
  const todayIdx = new Date().getDay() - 1;      // 월요일=0 이 되도록 보정
  const nowIdx = currentPeriod();

  const corner = document.createElement('div'); // 왼쪽 위 빈 칸
  corner.className = 'head';
  table.appendChild(corner);

  DAYS.forEach(function(d){                      // 요일 머리글
    const h = document.createElement('div');
    h.className = 'head';
    h.textContent = d;
    table.appendChild(h);
  });

  PERIODS.forEach(function(p, row){
    const t = document.createElement('div');     // 왼쪽 시간 칸
    t.className = 'time';
    t.textContent = p.time;
    table.appendChild(t);

    p.subjects.forEach(function(name, col){
      const cell = document.createElement('div');
      cell.className = 'cell' + (name ? '' : ' empty');
      if (row === nowIdx && col === todayIdx) cell.classList.add('now');
      const label = document.createElement('span');
      label.textContent = name || '-';
      cell.appendChild(label);
      const num = document.createElement('small');
      num.textContent = (row + 1) + '교시';
      cell.appendChild(num);
      table.appendChild(cell);
    });
  });
}

// 시계 : 1분마다 전체를 다시 그려 현재 교시 강조를 최신 상태로 유지
function tick(){
  const n = new Date();
  document.getElementById('clock').textContent =
    n.getFullYear() + '. ' + (n.getMonth() + 1) + '. ' + n.getDate() + ' ' +
    ['일','월','화','수','목','금','토'][n.getDay()] + '요일';
  updateDday();
  drawTable();
}

document.getElementById('planTitle').textContent = TITLE;
tick();
setInterval(tick, 60000);
</script>

②는 무드 조절판

하루씩 차이 난다시간까지 포함해 계산해서 소수점이 생김오늘 자정과 목표 자정을 비교하도록 통일. 코드의 today 만드는 줄을 같이 읽어봅니다
