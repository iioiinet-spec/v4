AI랑 같이 만드는
나만의 시간표 & D-Day

오늘 배울 기술은 딱 두 개입니다. 저장(Ctrl+S), 새로고침(F5). 나머지는 AI에게 부탁하면 됩니다. 아래 미션을 위에서부터 하나씩 해치우세요. 빈칸에 적은 내용은 이 브라우저에 저장되니, 실수로 창을 닫아도 다시 열면 그대로 있습니다.

준비 5분

코드를 넣을 빈 그릇부터 만듭니다. 여기서 막히면 손을 드세요.

  1. 바탕화면에 내시간표 폴더를 만듭니다.
  2. 메모장(또는 VS Code)을 열고 아무것도 쓰지 않은 채 저장합니다.
  3. 파일 이름은 index.html, 파일 형식은 반드시 모든 파일로 바꾸고 저장합니다.
  4. 저장된 파일을 더블클릭해 브라우저에 하얀 화면이 뜨면 성공입니다.
가장 많이 걸려 넘어지는 곳파일 형식을 "텍스트 문서"로 두면 index.html.txt가 되어 브라우저가 열지 못합니다. 제목 표시줄에 .txt가 보이면 다시 저장하세요.

미션 1 · 뼈대 받기 15분

AI에게 "그냥 만들어줘"라고 하면 매번 다른 게 옵니다. 조건을 붙이면 내가 고칠 수 있는 코드가 옵니다.

  1. 아래 프롬프트를 복사해 AI 채팅창(ChatGPT, Claude 등)에 붙여넣습니다.
  2. 받은 코드를 전부 복사해 index.html에 붙여넣고 저장합니다.
  3. 브라우저로 돌아가 새로고침. 숫자가 보이면 성공입니다.
HTML, CSS, JavaScript를 index.html 한 파일에 담아줘.
1) 화면 위쪽에 D-Day 카운터: 목표 이름과 남은 날짜를 크게 표시
2) 아래쪽에 월~금 5교시 시간표 표
3) 시간표 내용과 목표 날짜는 JS 맨 위 상수에 모아두고, 주석으로 "여기만 고치세요"라고 표시해줘
4) 초보자가 읽을 수 있게 모든 줄에 한국어 주석
5) 외부 라이브러리 없이, 설명은 코드 아래에 5줄 이내로
화면이 하얗게만 나온다면F12를 눌러 Console에 뜬 빨간 글씨를 그대로 복사해 AI에게 "이 오류가 났어. 이 부분만 고쳐줘"라고 보내세요.

미션 2 · 내 시간표 채우기 25분

아래 표에 내 진짜 시간표를 적으면, 코드에 붙여넣을 문장이 자동으로 만들어집니다. 빈 교시는 그냥 비워두세요.

위 표를 채우고 "내 코드 만들기"를 누르면 여기에 나옵니다.
어디에 붙여넣나요AI가 준 코드에서 여기만 고치세요 주석이 붙은 부분(TITLE, TARGET, PERIODS)을 찾아 통째로 바꿔치기하면 됩니다. 모르겠으면 AI에게 "이 코드를 어디에 넣어야 해?"라고 물어보세요.

미션 3 · 무드 고르기 25분

막혔을 때 에러 구조대

  
D-Day 자리에 NaN이 떠요
날짜 형식 문제입니다. 2026.12.10 이나 12/10 이 아니라 2026-12-10 처럼 적어야 합니다.

  
남은 날짜가 하루씩 차이 나요
컴퓨터가 시간까지 계산해서 그렇습니다. AI에게 "오늘 자정과 목표 자정을 기준으로 계산하게 고쳐줘"라고 부탁하세요.

  
폰트를 바꿨는데 안 변해요
폰트는 항상 두 군데입니다. 위쪽의 link 주소 한 줄, 아래쪽의 font-family 한 줄. 둘 다 같은 이름으로 맞춰야 합니다.

  
화면이 하얗게 비어요
따옴표나 중괄호가 하나 빠진 경우가 대부분입니다. F12 → Console의 빨간 글씨와 줄 번호를 AI에게 그대로 보내세요.

  
표가 한 줄로 길게 늘어져요
요일 개수와 칸 개수가 안 맞습니다. 한 교시에 과목이 정확히 5개씩 있는지 세어보세요.

  
AI가 코드를 통째로 새로 만들어요
"다시 만들어줘"라고 하면 그렇게 됩니다. "기존 코드는 그대로 두고 이 부분만 고쳐줘"라고 말하세요.
